# Project Statement

## Problem Statement
Hospitals and clinics often struggle to maintain structured digital records for patient registration, medical conditions, and billing in lightweight setups without complex database overhead. Manual record-keeping leads to calculation errors and data loss.

## Scope
This system handles patient onboarding, demographic and disease updates, deletion of records, billing calculations, data persistence via JSON, and terminal-based record displays.

## Target Users
- Small clinic administrators
- Desk receptionist staff handling admissions and billing

## High-Level Features
- CRUD Operations (Create, Read, Update, Delete Patients)
- Automated Billing & Fee Accrual
- Input Validation & Error Handling
- Persistent JSON Storage
