# Patient Management System

## Overview
A lightweight, terminal-based Python application for managing hospital patient records, billing, and persistence.

## Features
- Complete CRUD operations for patient records
- Financial charge tracking and invoice generation
- Persistent JSON storage
- Modular architecture with robust input validation

## Technologies
- Python 3.x
- JSON File Storage
- Unittest Framework
